# DummyPage

「本を楽しめるカフェ」Book Café Komorebi のホームページ(静的サイト)。

## 構成

- `index.html` - ページ本体(ヒーロー / コンセプト / メニュー / 本と空間 / アクセス / リクエスト・お問い合わせ)
- `style.css` - スタイル(レスポンシブ対応)
- `script.js` - モバイルナビ、メニュータブ、スクロール演出、フォーム検証

## 確認方法

`index.html` をブラウザで開く。

## 差し替えが必要な箇所

- 店名、住所、営業時間、メニュー内容と価格は仮のものです。
- 店内の様子は配色のみのプレースホルダーです。写真に差し替えてください。
- アクセスの地図は Google Map などの埋め込みに差し替えてください。
- お問い合わせフォームは送信処理がなく、入力チェックのみです。
